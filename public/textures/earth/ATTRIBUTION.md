# Earth textures

Higher-resolution maps added for the live Three.js globe. NASA imagery is
public domain (NASA/GSFC). Specular and normal maps come from the Three.js
examples planet set, which redistributes NASA-derived Earth data.

- `hi/earthmap.jpg`, `lo/earthmap.jpg` — NASA Blue Marble Next Generation
  (world.topo.bathy, December 2004), resampled from 5400×2700.
- `hi/earthlights.jpg`, `lo/earthlights.jpg` — NASA Black Marble 2016,
  resampled from 13500×6750.
- `*/earthclouds.jpg` — NASA Visible Earth cloud composite (2048×1024).
- `*/earthspec.jpg`, `*/earthnormal.jpg` — Three.js examples planet maps
  (2048×1024), NASA-derived.

Original 1k hero maps remain in this folder as fallbacks.
